1. 系统要求
================================================================================

  操作系统：Windows 10 / Windows 11（64位）
  内存：建议 8GB 及以上（Qwen2-1.5B模型运行需约2GB内存）
  磁盘空间：至少 3GB 可用空间
    - Python环境 + 依赖包：约 500MB
    - Ollama安装包：约 1.8GB
    - Qwen2-1.5B模型：约 934MB
  网络：安装过程需要联网下载


================================================================================
2. 环境准备（Python）
================================================================================

【步骤2.1】检查是否已安装Python
  打开 PowerShell 或 CMD，输入：
  
    python --version
  
  如果显示 Python 3.10.x 或更高版本，跳到第3步。
  如果提示"不是内部或外部命令"，需要安装Python。

【步骤2.2】下载Python
  访问 Python 官网：https://www.python.org/downloads/
  下载 Python 3.10 或 3.11 或 3.12 版本的 Windows installer (64-bit)。
  
  国内下载慢可使用淘宝镜像：
    https://registry.npmmirror.com/binary.html?path=python/

【步骤2.3】安装Python
  1. 双击下载的安装包
  2. ★★★ 重要：勾选底部的 "Add Python to PATH"（添加到环境变量）★★★
  3. 点击 "Install Now" 进行安装
  4. 安装完成后，重新打开 PowerShell，输入 python --version 验证

【步骤2.4】验证pip
  在 PowerShell 中输入：
  
    pip --version
  
  应显示 pip 版本号。如果报错，运行：
  
    python -m ensurepip --upgrade


================================================================================
3. 安装Python依赖包
================================================================================

【步骤3.1】打开PowerShell，进入项目目录
  
    cd "项目所在路径\AI摄影导师"
  
  例如：cd "F:\26毕设2\AI摄影导师"

【步骤3.2】安装依赖（推荐使用国内镜像加速）
  
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  
  该命令会自动安装以下4个包：
    - opencv-python  （图像处理与构图分析）
    - numpy          （数值计算）
    - PySide6        （GUI图形界面框架）
    - requests       （HTTP请求，调用Ollama API）

【步骤3.3】验证安装
  在 PowerShell 中逐行输入以下命令，确认无报错：
  
    python -c "import cv2; print('OpenCV:', cv2.__version__)"
    python -c "import numpy; print('NumPy:', numpy.__version__)"
    python -c "import PySide6; print('PySide6: OK')"
    python -c "import requests; print('requests: OK')"
  
  全部显示版本号或OK即表示安装成功。


================================================================================
4. 安装Ollama（本地大模型运行框架）
================================================================================

  Ollama 是一个本地运行大语言模型的工具，本项目使用它来部署Qwen2模型。

【步骤4.1】下载Ollama
  官方下载页：https://ollama.com/download
  点击 "Download for Windows" 下载 OllamaSetup.exe（约1.8GB）。
  
  ★ 如果官网下载速度慢，可使用以下国内加速地址：
  
  加速镜像1：
    https://mirror.ghproxy.com/https://github.com/ollama/ollama/releases/latest/download/OllamaSetup.exe
  
  加速镜像2：
    https://gh-proxy.com/https://github.com/ollama/ollama/releases/latest/download/OllamaSetup.exe
  
  将以上地址复制到浏览器地址栏回车即可开始下载。

【步骤4.2】安装Ollama
  1. 双击下载的 OllamaSetup.exe
  2. 按照安装向导完成安装（一路点 Next / Install）
  3. 安装完成后，Ollama 会自动在后台启动服务

【步骤4.3】验证Ollama安装
  打开新的 PowerShell 窗口，输入：
  
    ollama --version
  
  应显示 ollama version x.x.x，表示安装成功。
  
  再输入：
  
    ollama list
  
  此时应显示空列表（还没有下载模型），这是正常的。


================================================================================
5. 下载Qwen2模型
================================================================================

  Qwen2-1.5B 是阿里云开源的轻量化大语言模型，本项目用它生成摄影评语。

【步骤5.1】拉取模型
  在 PowerShell 中输入：
  
    ollama pull qwen2:1.5b
  
  该命令会从 Ollama 官方仓库下载 Qwen2-1.5B 模型（约934MB）。
  下载过程中会显示进度条和百分比。

  ★ 如果下载速度慢（低于100KB/s），可以尝试：
  
  方法A：使用代理加速（如果你有VPN/代理工具）
    在 PowerShell 中先设置代理再拉取：
    
      $env:HTTPS_PROXY="http://127.0.0.1:7890"
      ollama pull qwen2:1.5b
    
    其中 7890 替换为你的代理端口号。
    常见端口：Clash=7890, V2Ray=10809, SSR=1080
  
  方法B：耐心等待
    即使速度慢，只要没有报错就让它继续下载。
    934MB 在 50KB/s 的速度下大约需要 5 小时。

【步骤5.2】验证模型下载
  下载完成后（显示 success），输入：
  
    ollama list
  
  应显示类似：
    NAME            ID              SIZE      MODIFIED
    qwen2:1.5b     xxxxxxxx        934 MB    刚刚
  
  表示模型已就绪。

【步骤5.3】快速测试模型
  输入以下命令测试模型是否能正常运行：
  
    ollama run qwen2:1.5b "你好，请用一句话介绍自己"
  
  如果模型返回了中文回复，说明一切正常。
  按 Ctrl+D 或输入 /bye 退出对话。


================================================================================
6. 启动应用程序
================================================================================

【步骤6.1】确保Ollama服务正在运行
  Ollama 安装后默认会自动启动后台服务。
  可以在系统托盘（右下角）看到 Ollama 的图标。
  
  如果没有看到，手动启动：
    在 PowerShell 中输入：
    
      ollama serve
    
    保持该窗口不要关闭。

【步骤6.2】启动AI摄影导师
  打开新的 PowerShell 窗口，进入项目目录：
  
    cd "项目所在路径\AI摄影导师"
  
  运行主程序：
  
    python main.py
  
  应用窗口将会弹出。

【步骤6.3】确认启动状态
  观察应用左下角的状态提示：
  
  ● 绿色 "Ollama已连接，Qwen2就绪"  → 一切正常，可以使用全部功能
  ● 红色 "无法连接到Ollama服务"      → Ollama服务未启动，请执行步骤6.1
  ● 黄色 "未找到模型qwen2:1.5b"      → 模型未下载，请执行第5步

7. 功能使用说明
================================================================================

【7.1 上传图片】
  方式A：点击左侧 "选择图片" 按钮，从电脑中选择一张照片
         支持格式：JPG, JPEG, PNG, BMP, TIFF, WEBP
  
  方式B：点击 "示例图片" 按钮，从预设的4张在线摄影作品中选择
         （需要联网，图片会自动下载到本地）

【7.2 设置分析参数】
  构图规则：勾选要分析的规则
    - 三分法分析：检测图像兴趣点与三分线交点的距离关系
    - 对称性分析：计算图像水平/垂直方向的对称程度
    （可同时勾选两项）
  
  评语风格：选择AI评语的语言风格
    - 专业：详细的专业分析
    - 简洁：重点突出的简短评语
    - 鼓励：温暖肯定的鼓励式评语

【7.3 执行分析】
  点击 "开始分析" 按钮，系统将依次执行：
    1. 构图特征计算（OpenCV，约1-2秒）
    2. 可视化叠加图生成
    3. AI评语生成（Ollama + Qwen2，约5-15秒）
  
  分析过程中：
    - 左侧显示进度状态
    - 右侧上方显示环形分数（三分法/对称性各0-100分）
    - 中间显示可视化叠加图（三分线、兴趣点、对称轴）
    - 左下方显示量化特征数据
    - 右下方显示AI评语（流式逐字输出）

【7.4 交互式主体框选】
  在可视化分析图上，可以用鼠标拖拽框选照片中的主体区域。
  框选后：
    - 下方显示框选坐标和尺寸
    - 再次点击 "开始分析"，系统会聚焦分析框选区域
    - 点击 "清除框选" 可取消框选

【7.5 切换显示】
  点击右上角 "切换叠加层" / "显示原图" 按钮，
  可在原始图片和分析叠加图之间切换查看。

【7.6 历史记录】
  每次分析完成后，结果会自动保存到本地数据库。
  在左侧 "历史记录" 下拉框中可以查看和回顾之前的分析记录。
  点击 "清空" 可删除所有历史记录。

【7.7 导出报告】
  分析完成后，点击 "导出报告" 按钮，可将分析结果保存为：
    - TXT文件：包含量化数据和AI评语的文本报告
    - JSON文件：包含完整结构化数据的机器可读格式

8. 常见问题与解决方案
================================================================================

问题1：运行 python main.py 提示 "ModuleNotFoundError: No module named 'cv2'"
  原因：Python依赖包未安装
  解决：执行 pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

问题2：应用启动后显示 "无法连接到Ollama服务"
  原因：Ollama后台服务未运行
  解决：
    方法A：在系统托盘找到Ollama图标，确认正在运行
    方法B：打开PowerShell，运行 ollama serve

问题3：分析时报错 "无法读取图像"
  原因：图片路径包含特殊字符
  解决：已在代码中处理中文路径问题，如仍报错请将图片复制到英文路径下

问题4：AI评语生成很慢（超过30秒）
  原因：首次运行时模型需要加载到内存，后续会快很多
  解决：第一次分析耐心等待，后续分析速度会明显提升

问题5：ollama pull 下载模型超时
  原因：网络连接Ollama官方仓库不稳定
  解决：
    - 使用代理：$env:HTTPS_PROXY="http://127.0.0.1:7890"; ollama pull qwen2:1.5b
    - 多次重试：ollama pull 支持断点续传，重新执行即可继续下载

问题6：PySide6 界面显示模糊
  原因：高DPI缩放问题
  解决：程序已内置高DPI支持，如仍模糊可在Windows设置中调整缩放比例

问题7：pip install 安装依赖包很慢
  原因：默认使用国外PyPI源
  解决：使用清华镜像源
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

问题8：示例图片下载失败
  原因：Unsplash图片服务在国内可能不稳定
  解决：使用 "选择图片" 按钮从本地选择任意照片进行分析
