   AI摄影导师 - 更新教程（2026-05-08 修复版）

【本次修复内容】

1. 修复"叠加图缩放后消失"的问题
   - 之前：滚轮缩放图片时叠加图（三分线、对称轴等标记）会消失
   - 现在：缩放、平移、切换显示，叠加图始终保持显示

2. 修复"缩放中心漂移"的问题
   - 之前：平移图片后再用滚轮缩放，图片中心会漂移
   - 现在：缩放始终以图像中心为基准，平移偏移会同步缩放

3. 修复"AI评语格式不稳定"的问题
   - 之前：选择"简洁"风格但评语很长；段落有时分有时不分；标号有时标有时不标
   - 现在：三种风格（专业/简洁/鼓励）每种都有独立的固定模板：
     * 专业：300-400字，3段编号列表，专业严谨
     * 简洁：100-150字，3段一句话+关键数据，干练直接
     * 鼓励：200-280字，优点段占60%，温暖友好
   - 同时降低了AI生成的随机性参数，格式更稳定

============================================================

【更新方法（非常简单）】

第一步：找到你的AI摄影导师项目文件夹
       例如：F:\AI摄影导师\
       （就是放着 main.py 那个文件夹）

第二步：把本压缩包内的 3 个 .py 文件
       直接复制粘贴到该项目文件夹内
       （Windows 会提示是否覆盖，全部点"是/替换"即可）

       要替换的 3 个文件：
       ┌─────────────────────────┬──────────────────────────────┐
       │ 本压缩包内              │ 替换到项目文件夹的           │
       ├─────────────────────────┼──────────────────────────────┤
       │ gui_widgets.py          │ 同名文件 gui_widgets.py      │
       │ gui_main.py             │ 同名文件 gui_main.py         │
       │ llm_evaluator.py        │ 同名文件 llm_evaluator.py    │
       └─────────────────────────┴──────────────────────────────┘

第三步：双击运行 main.py（或者命令行 python main.py）
       即可使用更新后的版本。

【建议测试项目】

更新后，建议你做以下三项测试，验证修复效果：

测试一：叠加图缩放
  1. 上传任意一张图片
  2. 点击"开始分析"
  3. 等分析完成后，鼠标滚轮滚动放大缩小图片
  4. 确认三分线、对称轴等标记始终保持显示
  5. 点击"切换叠加层"按钮，应能在原图和叠加图之间无缝切换

测试二：缩放中心
  1. 鼠标右键拖动图片到一边
  2. 然后用滚轮缩放
  3. 确认缩放中心是图像中心，没有奇怪的漂移

测试三：评语格式
  1. 上传图片，先选"专业"风格 → 分析 → 评语应该是 300-400字、3段编号列表
  2. 再选"简洁"风格 → 重新分析 → 评语应该是 100-150字、每段一句话
  3. 再选"鼓励"风格 → 重新分析 → 评语应该温暖友好、优点段最长

【常见问题】

Q1: 替换文件后程序打不开了？
A1: 请检查你是否完整替换了 3 个文件，不要漏文件。
    并确认你的 Python 环境正常（依赖未变，requirements.txt 不需要改）。

Q2: 评语依然不规范？
A2: 请确认 Ollama 服务正在运行，并已下载 qwen2:1.5b 模型。
    模型本身有一定随机性，但本次修复已大幅降低不稳定概率。
    如果发现某个特定风格仍然异常，请告知具体场景。

Q3: 我之前的历史记录会丢吗？
A3: 不会丢失。本次只改了 3 个 .py 代码文件，
    历史记录文件（data/history.json 等）原封不动。
