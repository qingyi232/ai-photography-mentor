1. 项目概述与架构
================================================================================

  本项目是一款基于Python的桌面应用程序，实现图像构图的自动化分析与自然语言
  评语生成，扮演"AI摄影导师"角色。

  整体架构采用三层分离设计：
  
    ┌─────────────────────────────────────────────────┐
    │              表现层（GUI）                        │
    │   gui_main.py + gui_widgets.py (PySide6)        │
    ├─────────────────────────────────────────────────┤
    │              业务逻辑层                           │
    │   composition_analyzer.py  (OpenCV构图分析)      │
    │   llm_evaluator.py         (Ollama+Qwen2评语)   │
    ├─────────────────────────────────────────────────┤
    │              数据持久层                           │
    │   history_manager.py       (SQLite数据库)        │
    └─────────────────────────────────────────────────┘

  技术栈：
    - 开发语言：Python 3.10+
    - 视觉处理：OpenCV (opencv-python)
    - 数值计算：NumPy
    - GUI框架：PySide6 (Qt for Python)
    - LLM框架：Ollama (本地部署)
    - LLM模型：Qwen2-1.5B (阿里云开源)
    - 数据存储：SQLite3 (Python内置)
    - HTTP通信：requests

4. composition_analyzer.py - 构图分析模块（313行）
================================================================================

  职责：使用OpenCV实现三分法和对称性两种构图规则的自动化量化分析，
       并生成可视化叠加图。

  ┌─────────────────────────────────────────────────────────┐
  │  类：CompositionAnalyzer                                 │
  ├─────────────────────────────────────────────────────────┤
  │  公开方法：                                              │
  │    analyze(image_path, rules, roi) → dict               │
  │    draw_analysis_overlay(image_path, analysis) → ndarray│
  │    to_json() → str                                      │
  ├─────────────────────────────────────────────────────────┤
  │  私有方法：                                              │
  │    _analyze_rule_of_thirds(gray, w, h, roi) → dict      │
  │    _analyze_symmetry(gray, w, h, roi) → dict            │
  │    _thirds_description(score) → str                     │
  │    _symmetry_description(score) → str                   │
  │    _draw_dashed_line(img, pt1, pt2, color, ...)         │
  │    _draw_info_panel(img, analyses, w, h)                │
  └─────────────────────────────────────────────────────────┘

  【analyze 方法】（第16-57行）
    主入口方法，接收图片路径、分析规则列表和可选ROI区域。
    
    参数：
      image_path (str)  - 图像文件路径
      rules (list)      - 分析规则，默认 ["rule_of_thirds", "symmetry"]
      roi (tuple)       - 可选，主体框选区域 (x, y, w, h)
    
    返回值（dict）：
      {
        "image_path": "xxx.jpg",
        "image_size": {"width": 800, "height": 600},
        "roi": {"x": 100, "y": 50, "width": 200, "height": 150} 或 null,
        "analyses": {
          "rule_of_thirds": { ... },
          "symmetry": { ... }
        }
      }
    
    关键实现：
      第28行  cv2.imdecode(np.fromfile(...))
              使用numpy读取文件字节再解码，解决cv2.imread不支持中文路径的问题。
      
      第43-49行  ROI坐标裁剪
                 将用户框选的ROI坐标限制在图像合法范围内。

  【_analyze_rule_of_thirds 方法】（第59-112行）
    三分法构图分析核心算法。
    
    算法流程：
      1. 计算图像的4个三分线交点坐标：(w/3, h/3), (2w/3, h/3), 
         (w/3, 2h/3), (2w/3, 2h/3)
      2. 使用 cv2.goodFeaturesToTrack 检测图像中的角点（兴趣点）
         - maxCorners=50：最多检测50个角点
         - qualityLevel=0.01：角点质量阈值
         - minDistance=30：角点间最小距离
      3. 如果有ROI框选，则在ROI区域内检测角点，并将坐标转换为全图坐标
      4. 计算每个角点到最近三分交点的欧氏距离
      5. 取距离最小的前10个角点，计算平均归一化距离
      6. 评分公式：score = max(0, min(100, (1 - avg_dist * 5) * 100))
         距离越小分数越高，表示兴趣点越接近三分线交点
    
    返回值包含：
      - score (int, 0-100)：三分法得分
      - interest_points (list)：检测到的兴趣点坐标
      - third_points (list)：四个三分线交点坐标
      - avg_normalized_distance (float)：平均归一化距离
      - subject_center (dict)：主体中心坐标（仅当有ROI时）
      - subject_to_thirds_distance (float)：主体中心到最近三分点距离

  【_analyze_symmetry 方法】（第121-163行）
    对称性构图分析核心算法。
    
    算法流程：
      1. 水平对称分析：
         - 将图像沿垂直中线分为左右两半
         - 将右半部分水平翻转
         - 计算左半与翻转右半的像素差异均值
         - 评分：score = max(0, min(100, (1 - diff/128) * 100))
      2. 垂直对称分析：
         - 将图像沿水平中线分为上下两半
         - 将下半部分垂直翻转
         - 同样计算像素差异并评分
      3. 综合得分取水平和垂直中的较高分
      4. 如果有ROI框选，则仅在ROI区域内分析对称性
    
    返回值包含：
      - horizontal_symmetry.score (int)：水平对称得分
      - vertical_symmetry.score (int)：垂直对称得分
      - overall_score (int)：综合对称得分
      - best_axis (str)："horizontal" 或 "vertical"

  【draw_analysis_overlay 方法】（第192-260行）
    在原图上绘制分析可视化叠加层。
    
    绘制内容：
      1. 三分法网格线（白色虚线）
      2. 三分线交点标记（绿色十字+圆圈）
      3. 检测到的兴趣点（蓝色小圆点）
      4. 最佳对称轴（青色虚线）
      5. ROI框选区域（绿色边框+区域外变暗）
      6. 左上角半透明信息面板（显示分数和尺寸）
    
    使用 cv2.addWeighted 实现半透明叠加效果。

5. llm_evaluator.py - LLM评语生成模块（153行）
================================================================================

  职责：通过Ollama本地API调用Qwen2模型，将构图分析数据转化为
       通俗易懂的自然语言摄影评语。

  ┌─────────────────────────────────────────────────────────┐
  │  类：LLMEvaluator                                       │
  ├─────────────────────────────────────────────────────────┤
  │  常量：                                                  │
  │    DEFAULT_OLLAMA_URL = "http://localhost:11434"         │
  │    DEFAULT_MODEL = "qwen2:1.5b"                         │
  │    SYSTEM_PROMPT = "你是一位经验丰富的摄影导师..."        │
  ├─────────────────────────────────────────────────────────┤
  │  公开方法：                                              │
  │    check_connection() → dict                            │
  │    generate_comment(analysis_data, style) → dict        │
  │    generate_comment_stream(analysis_data, style) → iter │
  ├─────────────────────────────────────────────────────────┤
  │  私有方法：                                              │
  │    _build_prompt(analysis_data, style) → str            │
  └─────────────────────────────────────────────────────────┘

  【SYSTEM_PROMPT 系统提示词】（第15-22行）
    定义AI摄影导师的角色和行为规范：
      - 语言通俗易懂
      - 先优点后改进
      - 给出具体建议
      - 语气友好鼓励
      - 评语控制在200字以内

  【check_connection 方法】（第29-46行）
    检查Ollama服务是否可用，以及目标模型是否已下载。
    
    实现：
      - 请求 GET /api/tags 获取已安装模型列表
      - 检查 qwen2:1.5b 是否在列表中
      - 超时时间5秒
    
    返回值：
      {
        "connected": true/false,
        "target_model_available": true/false,
        "models": ["qwen2:1.5b", ...],
        "message": "状态描述文字"
      }

  【generate_comment_stream 方法】（第80-107行）
    流式生成评语，逐字输出，提升用户体验。
    
    实现：
      - 调用 POST /api/chat，设置 stream=True
      - 使用 requests 的 iter_lines() 逐行读取响应
      - 每行解析JSON，提取 message.content 字段
      - 通过 yield 逐片段返回文本
    
    API请求参数：
      {
        "model": "qwen2:1.5b",
        "messages": [
          {"role": "system", "content": "系统提示词"},
          {"role": "user", "content": "构图分析数据"}
        ],
        "stream": true,
        "options": {
          "temperature": 0.7,    // 生成多样性
          "top_p": 0.9,          // 核采样阈值
          "num_predict": 512     // 最大生成token数
        }
      }

  【_build_prompt 方法】（第109-152行）
    将结构化的构图分析数据转换为自然语言提示词。
    
    实现：
      - 根据评语风格（专业/简洁/鼓励）选择不同的风格描述
      - 将三分法得分、兴趣点数量、归一化距离等数据格式化
      - 将对称性水平/垂直/综合得分格式化
      - 拼接为完整的用户提示词

    表1：analysis_history（分析历史记录）
      - id              INTEGER  主键自增
      - timestamp       TEXT     分析时间
      - filename        TEXT     图片文件名
      - image_path      TEXT     图片完整路径
      - analysis_json   TEXT     分析结果JSON字符串
      - comment         TEXT     AI评语文本

      - key    TEXT  设置键名（主键）
      - value  TEXT  设置值

  【save_record 方法】（第52-76行）
    保存一条分析记录到数据库。
    从analysis字典中自动提取三分法和对称性得分存入独立字段，
    便于后续统计查询。返回新记录的ID。

  【get_all_records 方法】（第78-90行）
    获取所有历史记录，按ID倒序排列（最新的在前）。
    使用 sqlite3.Row 工厂函数将结果转为字典格式。
    自动将 analysis_json 和 rules_used 字段反序列化。

  【get_statistics 方法】（第108-130行）
    计算统计数据：总分析次数、平均三分法得分、平均对称性得分、
    最高三分法得分、最高对称性得分。使用SQL聚合函数实现。

7. gui_widgets.py - 自定义UI组件（261行）
================================================================================

  职责：定义应用的视觉风格常量和可复用的自定义UI组件。

  【Colors 类】（第9-28行）
    定义清新自然主题的颜色常量：
      - 主色调：森林绿 #5B8C5A（按钮、标题、高分指示）
      - 点缀色：暖棕 #D4A574（中等分数、导出按钮）
      - 背景色：淡绿灰 #F7F9F4（主背景）
      - 卡片色：纯白 #FFFFFF
      - 侧边栏：浅绿 #F0F4EC
      - 文字色：深绿灰 #2C3E2D
    
    设计理念：避免经典AI蓝紫渐变，采用自然清新配色，
    符合"摄影导师"的专业感和亲和力。

  【GLOBAL_STYLE 全局样式表】（第31-40行）
    Qt样式表(QSS)，定义全局字体、滚动条、工具提示等基础样式。
    使用 f-string 引用 Colors 常量，保持样式一致性。

  【ScoreRing 类】（第43-82行）
    环形分数显示组件，继承自 QWidget。
    
    功能：以环形进度条形式展示0-100分的构图得分。
    
    实现：
      - 重写 paintEvent，使用 QPainter 绘制
      - 底层灰色圆环 + 上层彩色弧形
      - 颜色根据分数自动变化：
        ≥70分 绿色（优秀）
        ≥40分 棕色（一般）
        <40分 红色（较弱）
      - 中心显示数字分数，底部显示标签文字
    
    公开方法：
      set_score(score, label)  更新分数和标签

  【CardWidget 类】（第88-102行）
    卡片容器组件，继承自 QFrame。
    
    功能：带标题、圆角边框、白色背景的内容容器。
    
    公开方法：
      add_widget(widget)  添加子组件
      add_layout(layout)  添加子布局

  【StyledButton 类】（第105-127行）
    统一风格按钮，继承自 QPushButton。
    
    支持4种类型：
      "primary"  - 绿色实心按钮（主要操作）
      "accent"   - 棕色实心按钮（次要操作）
      "outline"  - 绿色边框按钮（辅助操作）
      "default"  - 白色边框按钮（普通操作）
    
    每种类型包含 normal/hover/pressed/disabled 四种状态样式。

  【SelectableImageLabel 类】（第130-254行）
    支持鼠标框选ROI区域的图片标签，继承自 QLabel。
    
    功能：用户可在图片上拖拽鼠标框选主体区域，
    组件自动计算框选区域在原图上的实际坐标。
    
    信号：
      roi_selected(int, int, int, int)  框选完成时发射，参数为原图坐标
    
    关键方法：
      set_image(pixmap, orig_w, orig_h)  设置图片并记录原图尺寸
      get_roi_on_original() → tuple      获取原图坐标系下的ROI
      clear_roi()                        清除框选
    
    实现细节：
      - mousePressEvent：记录起始点，开始框选
      - mouseMoveEvent：实时更新框选矩形，限制在图片区域内
      - mouseReleaseEvent：计算最终ROI，发射信号
      - _update_display：重绘图片，叠加半透明遮罩和ROI边框
      - 坐标转换：label坐标 → 原图坐标，考虑图片缩放和居中偏移

10. 关键算法说明
================================================================================

  【三分法评分算法】
  
    三分法（Rule of Thirds）是摄影中最基本的构图法则，将画面用两横两竖
    四条线均分为九宫格，四个交点是视觉焦点位置。
    
    算法步骤：
    1. 计算四个三分交点坐标
    2. 使用Shi-Tomasi角点检测（goodFeaturesToTrack）找出图像兴趣点
    3. 对每个兴趣点，计算到四个交点的最短欧氏距离
    4. 用图像对角线长度归一化距离
    5. 取距离最小的前10个点的平均值
    6. 评分公式：score = clamp((1 - avg_dist × 5) × 100, 0, 100)
    
    分数含义：
      80-100：兴趣点非常接近三分线交点，构图优秀
      60-79 ：兴趣点较接近三分线交点，构图良好
      40-59 ：兴趣点与三分线交点有一定距离，构图一般
      0-39  ：兴趣点远离三分线交点，三分法构图较弱

  【对称性评分算法】
  
    对称性分析通过比较图像两半的像素差异来量化对称程度。
    
    算法步骤：
    1. 水平对称：沿垂直中线分割，右半翻转后与左半逐像素求差
    2. 垂直对称：沿水平中线分割，下半翻转后与上半逐像素求差
    3. 差异均值越小，对称性越强
    4. 评分公式：score = clamp((1 - mean_diff / 128) × 100, 0, 100)
       128是灰度图像差异的参考值（最大差异255的一半）
    5. 综合得分取水平和垂直中的较高分
    
    分数含义：
      80-100：图像具有很强的对称性，构图工整
      60-79 ：图像有一定对称性，构图较为均衡
      40-59 ：图像对称性一般
      0-39  ：图像对称性较弱，偏向非对称风格
